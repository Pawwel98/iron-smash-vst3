# IRON SMASH — Rock & Metal Drum Bus Enhancer (VST3)

Кастомный **VST3** плагин («улучшалка» для общей шины ударных в стилях рок и метал) в формате **One-Knob** на базе фреймворка **JUCE 7/8 + C++17**.

---

## Органы управления и интерфейс

1. **`INPUT` (слева сверху)** — регулятор входного уровня (`-24.0 dB … +24.0 dB`, по умолчанию стоит строго по центру в `0.0 dB`). Позволяет ослабить сигнал при повороте влево или сильнее раскачать секцию компрессии/транзиентов при повороте вправо. Двойной клик возвращает в `0.0 dB`.
2. **`OUTPUT` (справа сверху)** — регулятор выходного уровня обработанного сигнала (`-24.0 dB … +24.0 dB`, по умолчанию `0.0 dB`).
3. **`DRUM SMASH / ENHANCE` (большая центральная крутилка, `0% … 100%`)** — управляет тремя синхронизированными модулями рок/метал обработки барабанной шины:
   - **Двухполосный Transient Shaper (НЧ + ВЧ)**: выделяет полосу `< 165 Гц` (фундаментальный пинок бочки и тело малого барабана) и полосу `> 3.2 кГц` (щелчок колотушки кика, атака пластика и пружины снейра). С помощью дифференциальных огибающих (`fastEnv - slowEnv`) усиливает исключительно фазу атаки ударов (до `+8 дБ` в пике транзиента), повышая читаемость кика и снейра в плотной гитарной пачке без вытягивания гула комнаты.
   - **Тональный эквалайзер (+3…+5 дБ НЧ и ВЧ + чистка «коробочности»)**:
     - **Низ (`75 Гц Low-Shelf` + `145 Гц Bell`)**: плавный подъём до **`+3.0 … +4.5 дБ`** в рабочей зоне ручки для плотного панча бочки и веса снейра.
     - **Вырез мути (`360 Гц Bell`)**: сопутствующее ослабление до **`-2.0 дБ`** (`Q = 1.5`), убирающее «картонность» барабанной шины.
     - **Верх (`4.5 кГц Bell` + `8.5 кГц High-Shelf`)**: плавный подъём до **`+3.0 … +4.6 дБ`**, открывающий верхний щелчок снейра и атаку железа.
   - **Панчевая VCA-компрессия (Drum Bus Glue)**:
     - Атака **`25 мс`** (пропускает усиленный транзиент первых 25 миллисекунд удара) и быстрый релиз **`85 мс`** (успевает восстанавливаться на быстрых сбивках и кардане).
     - Фильтр верхних частот в цепи детектора (**`SC HPF 90 Гц`**), чтобы саб-низ бочки не пережимал всю шину.
     - Коэффициент сжатия до **`4:1`**, мягкое колено (`4 дБ`), автоматический Makeup Gain, лёгкое гармоническое насыщение (`tanh`) и параллельный подмес (**New York / Parallel Compression** до 85% Wet / 15% Dry).
4. **`BYPASS` (снизу слева)** — плавный безщелчковый обход всей обработки (10 мс кроссфейд).
5. **`LIMIT 0dB` (снизу справа)** — двухступенчатый барабанный лимитер с порогом **`0.0 dBFS`** (потолок `-0.05 dBFS`): сочетает мягкое насыщение верхушек транзиентов выше `-1.5 dBFS` (сохраняя субъективную громкость удара снейра) и мгновенный Brickwall-ограничитель (`0.05 мс` атака / `45 мс` релиз), гарантирующий отсутствие цифрового клиппинга выше `0 dB`.

## Как получить готовый файл `.vst3` (2 способа)

Так как бинарный файл `.vst3` компилируется под конкретную операционную систему (Windows x64 `.vst3` или macOS Universal `.vst3`), в проект включены скрипты автоматической сборки. CMake сам скачает нужную версию JUCE из официального репозитория — ничего вручную настраивать не нужно.

### Способ 1: Сборка в 1 клик на вашем компьютере

#### На Windows:
1. Убедитесь, что установлены [CMake](https://cmake.org/download/), [Git](https://git-scm.com/) и бесплатные **Visual Studio Build Tools** (компонент *Desktop development with C++*).
2. Запустите файл **`build_windows.bat`** двойным кликом.
3. Через 1–2 минуты готовый плагин появится по пути:
   `build\RockDrumEnhancer_artefacts\Release\VST3\Iron Smash Drum Enhancer.vst3`
4. Скопируйте папку `Iron Smash Drum Enhancer.vst3` в системную директорию VST3:
   `C:\Program Files\Common Files\VST3\`

#### На macOS (Intel + Apple Silicon M1/M2/M3/M4):
1. Убедитесь, что установлены Xcode Command Line Tools (`xcode-select --install`) и CMake (`brew install cmake`).
2. В терминале в папке проекта выполните:
   ```bash
   chmod +x build_macos.sh && ./build_macos.sh
   ```
3. Скопируйте собранный бандл `build/RockDrumEnhancer_artefacts/Release/VST3/Iron Smash Drum Enhancer.vst3` в:
   `~/Library/Audio/Plug-Ins/VST3/`

---

### Способ 2: Облачная сборка без установки компилятора (через GitHub Actions)

Если вы не хотите устанавливать Visual Studio или Xcode на свой компьютер:
1. Создайте бесплатный репозиторий на GitHub и загрузите туда содержимое этого архива.
2. Перейдите во вкладку **Actions** — workflow **`Build VST3 Plugin (Windows & macOS)`** (`.github/workflows/build_vst3.yml`) автоматически запустится и соберёт готовые `.vst3` плагины одновременно для **Windows (x64)** и **macOS (Universal Binary)**.
3. Скачайте готовый архив `IronSmash-VST3-Windows-x64` или `IronSmash-VST3-macOS-Universal` прямо со страницы завершения сборки и положите `.vst3` в папку плагинов вашей DAW (Reaper, Cubase, FL Studio, Studio One, Ableton Live, Logic Pro).
